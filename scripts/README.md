# scripts/

## import_data.py

Fetches benchmark results from the [tpu-spec-decode](https://github.com/aaronzhfeng/tpu-spec-decode) GitHub repo and transforms them into the CSV/JSON files the website expects in `data/`.

### Quick start

```bash
python scripts/import_data.py            # write data files
python scripts/import_data.py --dry-run  # preview without writing
```

No dependencies beyond the Python standard library (`urllib`, `csv`, `json`).

### What it produces

| Output file | Website chart | Source in tpu-spec-decode |
|---|---|---|
| `vllm_pipeline_tps_comparison.csv` | vLLM Pipeline TPS | `results/v4/vllm_pipeline_results.csv` + `eagle3_llama_results.csv` |
| `standalone_tpu_vs_gpu_tps.csv` | Standalone TPU vs GPU | `results/v5p/standalone_all_benchmarks.csv` |
| `acceptance_analysis.csv` | Acceptance Volume | `results/v5p/standalone_all_benchmarks.csv` + `results/v4/vllm_pipeline_*.csv` |
| `acceptance_rate_gpu_vs_tpu_standalone.csv` | Acceptance per Position | `results/v5p/standalone_*.json` (all 9 datasets) |
| `inference_replays.json` | Inference Demo | `results/v5p/standalone_*.json` (all 9 datasets) |
| `v5p_standalone_all_benchmarks.csv` | Summary Dashboard, Speedup, Category, Output Quality | `results/v5p/standalone_all_benchmarks.csv` (copied as-is) |
| `v5p_standalone_vs_v4.csv` | V5P vs V4 chart | `results/v5p/standalone_vs_v4.csv` (copied as-is) |
| `v5p_standalone_vs_gpu_paper.csv` | GPU Parity chart | `results/v5p/standalone_vs_gpu_paper.csv` (copied as-is) |

**Not generated by this script** (created separately):

| File | Source |
|---|---|
| `profiling_gsm8k.json` | Profiling data from tpu-spec-decode, fetched manually |
| `v4_standalone_all_benchmarks.csv` | V4 standalone benchmarks, fetched manually |

### Data source versions

- **Standalone results** use **V5P** data across all 9 datasets: gsm8k, math500, aime24, aime25, humaneval, mbpp, mt-bench, alpaca, swe-bench.
- **vLLM pipeline and Eagle3** use **V4** data (pipeline benchmarks were only run on V4).
- **GPU DFlash TPS** is estimated from the DFlash paper (Table 1, Qwen3-4B, temp=0) and is only available for the 4 math datasets.

### What still needs manual input

- **GPU acceptance curves**: The repo only has TPU standalone acceptance data. Add GPU rows to `acceptance_rate_gpu_vs_tpu_standalone.csv` if GPU standalone runs become available.
- **Replay output text**: Standalone JSONs contain TPS and `acceptance_lengths` but not decoded text. The script writes placeholder text.
- **Hero metrics**: After running the script, verify the headline numbers in `index.html` match the updated data.

### Re-running

Run the script again any time upstream benchmark data changes. It overwrites all files in `data/` with fresh results fetched from GitHub.
